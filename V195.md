# UBos 1.95

## Implemented scope; live testing still required

Interactive Node/npm/npx processes use WebContainer pseudoterminal input/output streams and xterm.js 5.5.0, with resize, pasted input, arrow keys and Ctrl+C forwarded to the process. The existing Stop button kills the process. This remains an argv-based runner, not Bash, and does not add pipes/redirection or guarantee every full-screen program works. If xterm cannot load, process execution is disabled rather than claiming stdin support. Virtual commands remain available.

npx is dispatched as its own executable, with its real arguments/output/exit code. Runtime availability and specific packages must be verified live. Packages execute network-capable code; ignore-scripts defaults true for npm lifecycle hooks, not as a guarantee against malicious explicitly invoked programs.

## Saved workspaces

The workdir is exported in WebContainer binary format, including node_modules and symlinks handled by that format, and stored in a separate per-project IndexedDB database. It restores before commands run. Initial workspace creation, completed processes, and explicit Node file writes save snapshots; dirty idle workspaces retry every 15 seconds. Running processes must stop before checkpoint/download. Saving on tab close is not relied on. A beforeunload warning is requested while changes are dirty, but browsers control whether it appears. node-save and node-shutdown await saving.

Snapshots are capped at 256 MB and stored transactionally with revision conflict checks. Failed/quota-exceeded saves leave the prior snapshot intact and report unsaved state. Supported browsers use a runtime-lifetime Web Lock to avoid concurrent-tab writers; revision checks remain a fallback. Local storage is not a guarantee of permanence. The Keep browser storage control requests navigator.storage.persist; denial is reported. Clearing site data or changing origin/profile can remove or hide the saved workspace. Backups may contain secrets from workspace files. Global npm installs are rejected because this version persists the workspace, not arbitrary filesystem locations. npx temporary caches outside the workdir are not guaranteed to persist.

Download ZIP/node-download exports the idle current workspace, including dependencies. Downloads are explicit, not silently triggered for each install. ZIP export also remains available when an IndexedDB save has failed, provided the runtime and export remain healthy. The existing UBos Files backup does not automatically include this separate database, and ZIP import is not implemented by this release. Keep source/lockfiles and rebuild packages or retain local browser storage as needed.

No page reload is needed between commands or for an idle node-shutdown/node-start cycle. Reopening/reloading UBos still requires a new runtime boot. Initial cross-origin isolation setup can still require its one-time reload, and runtime/CDN resources can require internet; no guaranteed offline runtime engine caching is claimed. The separate runtime page remains unchanged.

## App list

Workspace node_modules/.bin executable names are recorded with successful snapshots and registered in the desktop launcher and shortcuts. Opening a Node CLI app starts npm exec --offline -- <command> in an interactive Terminal. Removing a binary and saving removes its launcher entry. Regular npm libraries, arbitrary global packages, and temporary npx downloads do not automatically become GUI apps. Existing sandboxed HTML app installs remain separate.
