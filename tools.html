Algebra
Linear: bx + c = 0 → x = −c/b, b ≠ 0.
Quadratic: ax² + bx + c = 0 → x = (−b ± √(b²−4ac))/(2a), a ≠ 0.
(u+v)² = u² + 2uv + v²; (u−v)(u+v) = u²−v².
uᵐ × uⁿ = uᵐ⁺ⁿ for integer exponents where defined. u⁰ = 1 for u ≠ 0.
Geometry
Rectangle area = width × length. Triangle area = base × perpendicular height / 2.
Circle area = πr². Circumference = 2πr. Sphere volume = 4πr³/3.
Right triangle: a²+b²=c², with c the hypotenuse.
Trigonometry
In a right triangle: sin θ = opposite/hypotenuse; cos θ = adjacent/hypotenuse; tan θ = opposite/adjacent where defined.
180 degrees = π radians. sin² θ + cos² θ = 1.
