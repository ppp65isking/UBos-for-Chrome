# UBos 1.8 apps and Gaming Hub

This update preserves the already user-tested runtime files. It adds an explicit Node/npm Beta launcher that opens runtime/index.html in a separate browser tab; it does not claim package installation or persistent runtime projects are verified.

## Tools

Scientific arithmetic is handled by a restricted recursive-descent parser, not eval. It supports explicit multiplication, real-number functions and degree/radian selection. The equation solver accepts coefficients for ax²+bx+c=0, including linear, repeated-root, no-solution, infinitely-many-solution and complex-root cases. It is not a general symbolic solver. Geometry, percentage and length/mass/temperature conversion calculators plus basic reference sheets are included. Floating-point rounding and numerical range limitations apply.

## Gaming Hub

The Games entry becomes Gaming Hub. Existing Snake (including powers), Minesweeper, Space Shooter and bot Battle Royale are retained. Dino Runner adds jump/duck controls, increasing speed, cacti/birds, pause, saved best distance and two distance achievements. Each game also has an independent desktop/launcher app entry with its own window geometry. These entries use the shared game implementation with a direct-launch selector, rather than maintaining duplicate game source.

Achievements are shared locally across game windows under ubos.games.achievements. Existing best-score storage remains ubos.games.best. First-play, score, win and distance achievements cover every game. No account/cloud sync is added, and current general UBos backups may not include these keys. Keep site data if you want to preserve progress.

App metadata, desktop shortcuts, running-taskbar entries and launcher results use the bundled SVG icon helper. Installed apps receive a generic app icon. External ChatGPT website branding remains handled by its existing taskbar image/fallback.

This is an implementation commit, not evidence of browser-tested gameplay, equation accuracy across all inputs, or successful deployment. Test load order, app launchers, small screens, calculator domain errors and game achievements before treating the release as stable.
